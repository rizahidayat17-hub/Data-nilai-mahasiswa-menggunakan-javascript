# Data-nilai-mahasiswa-menggunakan-javascript
Proyek ini dibangun menggunakan arsitektur modular berbasis JavaScript modern (ES6 Modules) untuk memisahkan antara sumber data, kerangka tampilan, dan logika pemrograman. Penyelesaiannya dibagi menjadi 3 komponen utama:  Pemisahan Sumber Data (data.js)  Berfungsi sebagai pusat penyimpanan data mentah (database lokal sementara).
